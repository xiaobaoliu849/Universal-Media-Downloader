GET STARTED

三步上手，极简体验

01

获取并解压客户端

前往 Releases 页面下载最新版本的 Windows 绿色压缩包，解压到任意文件夹（无需 Python 环境）。

02

双击运行程序

双击打开 Universal Media Downloader.exe，系统将自动在浏览器中唤起控制面板。

03

粘贴链接即刻下载

将想下载的视频链接粘贴到输入框，按回车或点击“下载媒体”，尽享高速原画体验！
